# Артефакт 2 - тестовая стратегия

---

## 1. Цель

- Убедиться, что процессинговая цепочка проходит целиком: терминал $\rightarrow$ Gateway $\rightarrow$ Switch $\rightarrow$ Authorization $\rightarrow$ Card Management
- Убедиться, что решение об авторизации корректно: валидные операции одобряются, невалидные отклоняются
- Убедиться, что код отказа соответствует причине отказа

## 2. Объект тестирования

- **Ядро**: Authorization, Card Management
- **Периферия**: Gateway, Switch, симуляторы, Transaction Logger, Web Dashboard

## 3. Уровни проверок

| Уровень                     | Что проверяем                                                  |
| --------------------------- | -------------------------------------------------------------- |
| Интеграционное тестирование | Взаимодействие сервисов (Authorization $\rightleftarrows$ CMS) |
| E2E                         | Сквозной путь транзакций                                       |

## 4. Область тестирования

- **Входит в область:**
  - **Авторизация**: статусы карт, лимиты (дневной/месячный), баланс, срок действия
  - **Управление картами**: CRUD, алгоритм Луна, генерация карт, резервирование

- **Не входит в область:**
  - **Внешний процессинг чужих BIN:** Система эмулирует закрытый контур банка-эмитента; межбанковский клиринг не тестируется ввиду учебного упрощения. Обоснование — архитектурный принцип «только свои карты»: СМП обрабатывает исключительно карты из Card Management, понятие внешних BIN отсутствует.
  - **Аппаратные криптомодули и генерация реальных PIN/CVV блоков:** Проверки CVV и PIN валидируются на уровне заглушек (stubs) согласно ТЗ.
  - **Нагрузочное тестирование:** Не хватает ресурсов для воспроизведения (временных и аппаратных)

## 5. Приоритезация

Риск-ориентированный подход:

1. **Критический** - Authorization: принимает решение по деньгам, единственная точка отказа
2. **Высокий** - CMS: источник данных для всех, без карт СМП не работает
3. **Средний** - Switch, Gateway: маршрутизация и точка входа
4. **Низкий** - Dashboard, симуляторы: не влияют на деньги
